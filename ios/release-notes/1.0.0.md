# Cold Gas 1.0.0

The first builds of the native app, for the team only. It is the foundation, not the game yet: the stage, the
controls, the HUD and the results come in the next phases (docs/NATIVE.md §10). Builds within 1.0.0 share these
notes, so they change as each phase lands.

## What is in this build
- **The sim is the web's, bit for bit.** The Swift port flies all 52 run vectors to the same bits as the JS sim, and
  scores them with the same card.
- **The roadster, drawn in Metal at 120 Hz.** It turns on the stage with a line of frame and GPU timings at the top.
- **Haptics.** The haptic engine starts at launch, with a level you can change. The run's haptic track itself plays
  from the same feed as the web's, but only from the developer tools in this build.

## What to test
- Open it and leave it running for a minute. The timings line should hold near 8.3 ms a frame on a ProMotion iPhone.
- Close it and reopen it: the second launch should set up faster (the pipeline cache).
- Tap the text at the top to step the haptics level. Each step should give a light click.
- On an iPhone Duo, fold and unfold it while it runs. The car should stay centred, and each fold position gives a
  light tick.
- Anything that crashes, stutters or looks wrong: send it from TestFlight with a screenshot.

## Our promises
No accounts, no ads, no tracking. This build makes no network calls at all.
